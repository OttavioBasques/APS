🌿Respira Urbana

Clima e qualidade do ar, servidos por um API Gateway que orquestra três microsserviços.

    geocodificação
    clima
    qualidade do ar

    Busque uma cidade ou use sua localização para começar. O gateway consulta os serviços de clima e qualidade do ar em paralelo — se um deles cair, o outro card ainda aparece.

    Arquitetura: este cliente fala apenas com o API Gateway. O Gateway chama três microsserviços internos (geocodificação, clima, qualidade do ar), guarda respostas no Redis por alguns minutos e usa esse cache quando um serviço está fora do ar. Um quarto serviço, separado, escuta alertas de qualidade do ar publicados via Redis Pub/Sub — de forma totalmente assíncrona.
